# موقع برقوش ERP — قالب WordPress

قالب مخصّص لموقع [brqosh-erp.com](https://brqosh-erp.com/) يحلّ محلّ قالب Hostinger AI. عربي RTL بهوية برقوش
البرونزية (`design-system/BRAND.md`)، وكل ادعاء في المحتوى مُطابَق مع الكود في `src/`.

## الهيكل

| المسار | المحتوى |
|---|---|
| `wordpress-theme/brqosh/` | القالب: `front-page.php` و`page-<slug>.php` لكل صفحة، و`inc/` للمنطق |
| `inc/content.php` | المحتوى كبيانات: الأقسام، القطاعات، الأسئلة، سجل الإصدارات |
| `inc/forms.php` · `inc/leads.php` · `inc/validation.php` | النماذج ومعالجتها وتخزين الطلبات والتحقق |
| `inc/security.php` | تقوية الواجهة العامة |
| `tests/validation-test.php` | اختبارات المدقّقات (متجهات رقم الطلب مولّدة من كود C# الفعلي) |
| `tools/build-theme.py` | يفحص ويبني `dist/brqosh-theme-<ver>.zip` |

## الصفحات

| الصفحة | الحالة |
|---|---|
| الرئيسية، المميزات، الأسعار، التحميل، التفعيل، من نحن، تواصل، التجربة | أُعيد تصميمها |
| **القطاعات** `/sectors/` | جديدة — 8 قطاعات لها وحدات فعلية في البرنامج |
| **الفوترة الإلكترونية** `/e-invoicing/` | جديدة — أهم سؤال للمشتري، بصياغة لا تدّعي اعتماداً لم يتم |
| الخصوصية، الشروط، الاتفاقية | تبقى نصاً في المحرر (`page.php`) لأنها تحتاج مراجعة قانونية |
| «سجل التحديثات» كصفحة منفصلة | أُلغي — صار قسماً `#changelog` في صفحة التحميل |

## النماذج

التجربة والتواصل والتفعيل تُرسل إلى `admin-post.php` (لا واتساب فقط كما كان)، وتُحفظ في
**لوحة التحكم ← الطلبات الواردة** (للمدير فقط) وتُرسل بالبريد. الحماية: فخ honeypot، رمز زمني موقّع
(يعمل مع التخزين المؤقت للصفحات)، تحقق من المصدر، حدّ 5 طلبات/ساعة لكل IP، وتحقق صارم من الحقول —
ومنها رقم الطلب `BRQ-…` بخانتَي التحقق نفسيهما في البرنامج. الطلبات تُحذف تلقائياً بعد 365 يوماً (قابل للتعديل).

## النشر

```bash
python3 website/tools/build-theme.py
```

1. خذ نسخة احتياطية من الموقع (Hostinger ← Backups).
2. لوحة التحكم ← المظهر ← قوالب ← إضافة ← رفع القالب ← `website/dist/brqosh-theme-1.0.0.zip` ← تفعيل.
   عند التفعيل تُنشأ الصفحات الناقصة فقط (sectors, e-invoicing)، ولا يُعدَّل شيء موجود.
3. المظهر ← تخصيص ← **إعدادات برقوش**: راجع البريد والجوال والعنوان، وأضف السجل التجاري والرقم الضريبي.
4. اختبر نموذج التواصل وتأكد من وصول البريد. إن لم يصل، فعّل SMTP (إضافة Hostinger أو WP Mail SMTP).
5. امسح ذاكرة LiteSpeed Cache.

## عند كل إصدار للبرنامج

أضف ملاحظات الإصدار في أول `brqosh_releases()`، ثم حدّث الحجم والبصمة من **التخصيص ← الإصدار والتحميل**.
سكربت البناء يرفض إذا لم يطابق أحدث إصدار `1.1.<version.txt>`.
