## 1. المتطلبات

| المكوّن | الحد الأدنى |
|---------|-------------|
| نظام التشغيل | Windows 10/11 x64 |
| بيئة التشغيل | [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0) |
| قاعدة البيانات (إنتاج) | **PostgreSQL 15+** (يُفضّل 16+) |
| قاعدة البيانات (تطوير) | SQLite تلقائي أو PostgreSQL |
| قرص | ≥ 2 GB حر للنشرات والنسخ |

متغير الإنتاج:

```powershell
[Environment]::SetEnvironmentVariable("BRQOSH_ENV", "production", "Machine")
```

راجع التفاصيل في [`docs/postgres-production.md`](../docs/postgres-production.md).

## 2. تثبيت MSI

```powershell
# مرة واحدة لبناة الحزمة — ثبّت v5 صراحةً: v7+ يرفض البناء بلا قبول رسوم
# صيانة (Open Source Maintenance Fee EULA)، وهو قرارٌ لا يُتّخذ آلياً.
dotnet tool install --global wix --version 5.0.2
.\installer\publish.ps1
.\installer\build-msi.ps1
```

ناتج: `dist\BRQOSH-Setup.msi` + اختصارات قائمة ابدأ وسطح المكتب.

**على جهاز نظيف (Pilot):**

1. ثبّت .NET 9 Desktop Runtime إن لزم (المُنصِّب يرفض التثبيت بدونه)  
2. جهّز خادم PostgreSQL وقاعدةً ودورَ تطبيقٍ **وفعّل `ssl=on`** كما في [`docs/postgres-production.md §3`](../docs/postgres-production.md) — خطوةُ ④ تشترط TLS افتراضاً  
3. ثبّت `BRQOSH-Setup.msi` — يضبط `BRQOSH_ENV=production` بنطاق الجهاز ويضع علامة `brqosh.environment` بجوار الملف التنفيذي  
4. شغّل BRQOSH → في معالج التهيئة أدخل بيانات الاتصال بالقاعدة (القسم ④) واضغط **اختبار الاتصال** ثم **ابدأ العمل الآن** — يُكتب `%APPDATA%\BRQOSH\database.json` محميّاً بـDPAPI تلقائياً  
5. فعّل الترخيص (القسم 4 أدناه) → سجّل الدخول  
6. نفّذ `tools/FullScenarioAudit` وتوثيق SUCCESS  

> **(CEEF-236 · ت-٣)** كانت الخطوةُ الرابعة «أنشئ `database.json` (القسم 3)» — والقسمُ 3 هو
> معالجُ التهيئة لا صيغةُ الملفّ، ولا شاشةٌ كانت تكتبه، فكان المشغّلُ يؤلّف JSON بكلمة مرور
> صريحة. الكتابةُ باليد لا تزال ممكنةً (الصيغة في `docs/postgres-production.md §2`) لكنها
> لم تعد الطريقَ الوحيد.  

نشر محمول بدون MSI:

```powershell
.\installer\publish.ps1
# الناتج: dist\BRQOSH
```

## 3. التشغيل الأول (Setup Wizard)

عند أول تشغيل بدون إعداد مكتمل:

1. اختيار نظام العمل (محاسبة / مقاولات / تصنيع / تجزئة / …)  
2. اسم المنشأة + الرقم الضريبي (15 خانة)  
3. إنشاء مستخدم المدير وكلمة المرور (سياسة 12+ حرفاً)  
4. **بيانات الاتصال بقاعدة PostgreSQL** (الخادم · المنفذ · القاعدة · المستخدم · كلمة المرور) — تُجرَّب بزرّ **اختبار الاتصال** ويُرفض الإكمال إن أخفقت، ثم تُحفظ محميّةً في `%APPDATA%\BRQOSH\database.json`. **و«اشتراط اتصال مشفّر (TLS)» مؤشَّرٌ ابتداءً** فتُكتب `SSL Mode=Require`؛ لا تُزله إلا إن كان الخادم على الجهاز نفسه — ويلزم عندئذٍ `ssl=on` على خادم PostgreSQL وإلا أخفق الاختبار برسالةٍ تُسمّي السبب. خارج الإنتاج يظهر خيار SQLite محلية للتجربة  
5. تهيئة الدليل المحاسبي السعودي والفترات عند أوّل إقلاع  

بعد الإكمال تُحفظ الحالة في مخزن الإعداد المحلي ولا يُعاد المعالج. إن وُجد `database.json` سابقاً تُملأ حقولُه ويُترك حقلُ كلمة المرور فارغاً للإبقاء عليه.

## 4. تفعيل الترخيص

**لا يلزم أيُّ ملفِّ مفتاحٍ على جهاز العميل** — مفتاحُ الثقة العامّ مُضمَّنٌ في التطبيق
(`EmbeddedLicenseKeys.PublicKeyPem`)، وفي الإنتاج لا يُقرأ غيرُه.

على جهاز العميل:

1. عند أوّل إقلاعٍ إنتاجيّ تظهر نافذةُ التفعيل تلقائياً (أو لاحقاً من **إعدادات المنشأة → الترخيص**)  
2. انسخ **معرّف الجهاز** وأرسله مع اسم المنشأة **كما هو مكتوب في المعالج** إلى المورِّد  
3. الصق ملفَّ الترخيص الصادر كاملاً واضغط **تفعيل** — كلُّ إخفاقٍ يُعرض بسببه (منشأةٌ أخرى · جهازٌ آخر · منتهٍ · توقيعٌ ليس من المورِّد · نصٌّ ليس ترخيصاً)  
4. في الإنتاج لا تُمنح فترة تجربة — التفعيل إلزامي  

عند المورِّد (بالمفتاح الخاصّ المحفوظ خارج المستودع):

```powershell
dotnet run --project tools/LicenseIssuer -- sign "<اسم المنشأة>" <معرّف الجهاز> <license-private.pem> [الأيام]
```

> **(CEEF-236 · ت-١/ت-٢)** كان المفتاحُ العامُّ يُقرأ من `%APPDATA%\BRQOSH\license-public.pem`
> أو متغيّرِ بيئة، ولا يشحنه المُنصِّب — فكان ترخيصُ المورِّد الصحيحُ يُرفض على كلّ جهازٍ نظيف؛
> وكان العميلُ يستطيع استبدالَ الملفّ بمفتاحه والتوقيعَ لنفسه. **تبديلُ المفتاح المُضمَّن يُبطل كلَّ
> ترخيصٍ صادرٍ قبله** — فهو قرارُ إصدار. وللتحقّق على جهازٍ نظيف: `dotnet run --project tools/LicenseProbe -- --private <license-private.pem>`.

## 6. النسخ الاحتياطي والاستعادة

| السكربت | الاستخدام |
|---------|-----------|
| `scripts/backup-postgres.ps1` | `pg_dump -Fc` يومي |
| `scripts/restore-postgres.ps1` | استعادة إلى بيئة اختبار/تعافٍ |
