# ‏(م-١ · ن-٠١) ‏دفترُ الإصدارات المشحونة — سطرٌ لكلّ `ProductVersion` غادر إلى عميل.
#
# ‏`build-msi.ps1` يرفض بناءَ حزمةٍ برقمٍ مُسجَّلٍ هنا. والسبب: `AllowSameVersionUpgrades`
# ‏يُنقذ الترقيةَ حين يتساوى الرقمان، لكنّه لا يجعل التساويَ صحيحاً — إصداران بالرقم
# ‏نفسِه لا يُميَّزان في «إضافة وإزالة البرامج» ولا في سجلّ عطلٍ ولا في بلاغِ عميل.
#
# ‏**يُضاف السطرُ عند الشحن لا عند البناء.** بناءٌ محلّيٌّ للتجربة لا يُسجَّل.
#
# ‏الصيغة: ثلاثةُ حقول (‏major.minor.build) — وهي وحدَها ما يقارنه Windows Installer.
#
# ‏ملاحظة: `1.0.0` **غيرُ مُسجَّلٍ عمداً**. الحزمةُ التي حملته لم تصل عميلاً (لا تنصيبَ
# ‏قائمٌ عند أحد وقتَ كتابة هذا)، ولو سُجِّل لمَنَع البناءَ المحلّيَّ الذي رقمُه `1.0.0`.
