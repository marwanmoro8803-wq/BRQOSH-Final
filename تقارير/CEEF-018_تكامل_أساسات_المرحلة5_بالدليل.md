## 0. ما كان ناقصاً في CEEF-017 (اكتشاف بالدليل)

قبل هذا التقرير، `rg DomainEventHub.PublishAsync` داخل `src/` كان **صفر** خارج تعريف الـ publisher.  
أي أن Domain Events وBranch وCurrencies وُجدت كأنواع، **دون مسار تشغيلي يثبت استخدامها**.

هذا التقرير يغلق تلك الفجوة حيث أمكن داخل نطاق الدورة التجارية الأساسية.

## 2. ما أصبح موصولاً فعلياً

### 2.1 Domain Events — مسارات مثبتة باختبار تكامل

| الخدمة | الحدث | اختبار |
|--------|--------|--------|
| `JournalPostingService` | `JournalEntryPostedEvent` | `JournalPosting_Publishes_JournalEntryPostedEvent` |
| `SalesInvoicePostingService` | DocumentPosted + JournalPosted | `SalesInvoicePosting_Publishes_DocumentAndJournalEvents` |
| `CreditNotePostingService` | DocumentPosted + JournalPosted | (يغطيها مسار الترحيل بعد الربط) |
| `PurchaseInvoicePostingService` | DocumentPosted + JournalPosted | مسار المشتريات |
| `DebitNotePostingService` | DocumentPosted + JournalPosted | مسار المدين |
| `GoodsReceiptPostingService` | DocumentPosted | مسار GRN |
| `SalesInvoiceCancellationService` | DocumentCancelled | إلغاء مبيعات |
| `PurchaseInvoiceCancellationService` | DocumentCancelled | إلغاء مشتريات |

آلية التوصيل: `DomainEventHub` (ثابت متزامن مع DI عبر `AddBrqoshInfrastructure`).

### 2.2 Branch — ليس stub فقط

- `DatabaseInitializer.SeedHeadquartersBranchAsync` ينشئ `HQ` عند أول تهيئة.
- إثبات: `Initialize_SeedsHeadquartersBranch_AndSarCurrency`.

### 2.3 العملات — ليست حقلاً مخفياً فقط

- `Company.SetCurrencies` + حقول في `CompanySettingsPage` (عرض/حفظ).
- ترقية مخطط: `BaseCurrencyCode` / `FunctionalCurrencyCode`.

### 2.4 API harden — مثبت باختبار

- `ApiKeyGuardTests` (3 اختبارات) تثبت 401 / health / قبول المفتاح.

## 3. ما لم يُغلق (صراحة — لتجنب التمنيق)

| البند | الواقع |
|-------|--------|
| نشر أحداث لكل orchestrators | **غير مكتمل** — باقٍ بلا Publish: سندات قبض/صرف، شيكات، مستخلصات، رواتب، أصول، حركات مخزون يدوية، بعض مسارات الإلغاء |
| `BranchId` على الفواتير/المخزون | **غير منفّذ** — الفرع موجود ومزروع، المستندات لا ترتبط به بعد |
| FX revaluation / قيود فروقات عملة | **غير منفّذ** — `FxConversion` حسابي فقط |
| Multi-tenant SaaS / Cloud HA / BI / AI / Mobile | **خارج النطاق** |
| Load 1M قيد | harness لـ 200 في CI فقط؛ 1M يحتاج بيئة تشغيلية |
| Pen test / OWASP ZAP حي | قائمة تحقق مكتوبة؛ المسح الحي غير مشغَّل هنا |
| تغطية 75% لكل الحل في CI gate | Coverlet يجمع artifact؛ **لا يوجد fail-gate** على نسبة التغطية بعد |
