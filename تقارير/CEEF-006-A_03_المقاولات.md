# CEEF-006-A — المراجعة العميقة (3) المقاولات

**الدرجة: 5.5 / 10** — مستخلصات + VAT + قيود **جيدة**؛ ذمم مقاولين وضوابط عقد **ناقصة**.

---

## المعمارية

```
ProgressBilling → قيد (AR + محتجز + إيراد + VAT) → ZATCA
SubcontractAgreement → Withhold → AP + Retention Payable
RetentionRelease → عكس محتجز (عميل / مقاول)
ConstructionProject + BOQ + Contract (منفصلة عن الترحيل)
```

**ملاحظة:** لا يوجد **WIP مقاولات** — `WipPage` لتصنيع فقط (`WipQuery` → `WorkOrder`).
