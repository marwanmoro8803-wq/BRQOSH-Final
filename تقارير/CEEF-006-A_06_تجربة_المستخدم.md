## Test Cases (E2E / UiAudit)

1. **Role matrix:** لكل دور — قائمة الصفحات الظاهرة = المسموحة فقط.
2. **Transfer E2E:** نجاح UI + persistence DB.
3. **MustChangePassword:** حظر MainWindow حتى تغيير كلمة المرور.
4. **VAT page:** شركة Construction — ظهور صف مستخلصات.
5. **ar-SA header:** مقارنة تاريخ الهيدر بتقارير Gregorian.
6. **Login Enter key:** PasswordBox + Enter → authenticated.

**ملاحظة:** `tools/UiAudit` ما زال يستخدم admin123 — **فاشل** بعد CEEF-003.

## فرصة تنافسية UX

1. **واجهة عربية كاملة** مع مصطلحات محاسبة سعودية (محتجز، مستخلص، إقرار).
2. **معالج ZATCA CSID** مدمج — نادر في المنافسين المحليين.
3. **POS + فاتورة فورية** في نفس المنتج.
4. بعد إصلاح الصلاحيات: **أدوار جاهزة** (محاسب، كاشير، مدير، عارض).
