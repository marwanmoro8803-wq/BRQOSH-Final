## 2. منهجية التدقيق (كما طلبت — بشري + آلي)

1. **تجهيز بيانات حقيقية** عبر `FullScenarioAudit` (عملاء/موردون/فواتير/قيود/تقارير).
2. **مزامنة كلمة مرور المديرين** مع `BRQOSH_TEST_PASSWORD` + تحقق API: `[PASS] تحقق دخول «marwan»`.
3. **تشغيل Desktop** مع `BRQOSH_UITEST=1`.
4. **دخول حي:** اسم مستخدم + كلمة مرور عبر UIA (معرّفات `LoginUsername` / `LoginSubmit`).
5. **لكل صفحة:** تنقل → انتظار بيانات → فحص جدول/KPI → كل زر (حوار/حفظ/تقرير/PDF/تنبيه).
6. **حفظ فعلي:** عميل جديد، مورد، صنف، مستودع، مركز تكلفة، حساب بنكي — `[PASS] إدخال + حفظ`.
7. **نوافذ فرعية:** فتح وإلغاء/حفظ ثم إغلاق MessageBox.
