## 1. مسار التشغيل الفعلي (Desktop)

```
App.OnStartup
 → setup.json مكتمل؟ وإلا Wizard (إلغاء → Shutdown)
 → LoadDatabaseConfig (إنتاج = PostgreSQL إلزامي)
 → EnsureDatabaseReachable
 → DatabaseBootstrap (شركة · دليل حسابات · مستودع · HQ · ZATCA defaults · Admin)
 → License (أو تجربة / UITEST)
 → Login → (MustChangePassword؟)
 → MainWindow + تنقل حسب Profile + PermissionService
 → ترحيل عبر خدمات Infrastructure + SecurityContext
```

**ثغرة مُصلَحة:** في الإنتاج كان `WireDomainEventPersistence()` يُتخطّى بعد ضبط PostgreSQL → أحداث النطاق تبقى في الذاكرة فقط. الآن يُستدعى قبل `return`.
