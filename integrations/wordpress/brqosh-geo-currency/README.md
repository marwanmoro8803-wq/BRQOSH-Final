# Brqosh Geo Currency — عملة بلد التوصيل في السلة وإتمام الطلب

## المشكلة

متجر brqosh.com يحوّل الأسعار عبر سكربت JavaScript في القالب الابن (`brqosh-astra-child`)، وهذا السكربت:

- يغيّر **العرض فقط**؛ WooCommerce يبقى يحسب ويُنشئ الطلب بالريال.
- يستثني صراحةً `.woocommerce-cart` و`.woocommerce-checkout` و`.woocommerce-order-received`، لذلك صفحة إتمام الطلب تبقى بالريال حتى لو اختار العميل البحرين.

## الحل

إضافة WordPress تغيّر العملة **فعلياً من جهة الخادم** حسب بلد التوصيل:

| بلد التوصيل | العملة | الكسور المعروضة |
|---|---|---|
| السعودية | SAR | 2 |
| الإمارات | AED | 2 |
| الكويت | KWD | 3 |
| البحرين | BHD | 3 |
| قطر | QAR | 2 |
| عُمان | OMR | 3 |
| الأردن | JOD | 3 |
| مصر | EGP | 2 |
| فلسطين | ILS | 2 |
| أي بلد آخر | SAR | 2 |

- يُحدَّد البلد تلقائياً من موقع الزائر الجغرافي (أو من اختياره في زر العملة بالهيدر) ويُعبّأ مسبقاً في حقل البلد بصفحة الدفع.
- تغيير البلد في نموذج الدفع يغيّر العملة والأسعار والشحن والكوبونات فوراً.
- الطلب يُسجَّل بعملة العميل، ويُحفظ معه سعر الصرف (`_bq_fx_rate`) والمعادل بالريال يظهر في صفحة الطلب بلوحة التحكم.
- يعمل مع صفحة الدفع الكلاسيكية والـ Blocks وخطوات CartFlows.
- أسعار الصرف حيّة من `open.er-api.com` (بدون مفتاح وبدون حساب)، تُخزَّن 6 ساعات. إن تعذّر الاتصال تُستخدم أسعار الربط الرسمية بالدولار لعملات الخليج والأردن؛ والعملات العائمة (KWD/EGP/ILS) تبقى بالريال حتى يعود المصدر.
- بقية صفحات المتجر تبقى بالريال على الخادم كما هي (لا يتأثر LiteSpeed Cache ولا سكربت القالب).

## التثبيت

1. لوحة التحكم ← **إضافات ← أضف جديد ← رفع إضافة**.
2. ارفع `brqosh-geo-currency.zip` ثم **تفعيل**.
3. **LiteSpeed Cache ← لوحة التحكم ← مسح الكل (Purge All)**.

لا توجد إعدادات. للتعطيل يكفي إلغاء تفعيل الإضافة.

## ملاحظات تشغيلية

- **التحويل البنكي (BACS)** يعمل بأي عملة: العميل يُطالَب بالمبلغ بعملته.
- **PayPal** لا يدعم SAR ولا BHD/KWD/AED أصلاً؛ وضعه لا يتغير بهذه الإضافة.
- التقريب لأقرب 0.01 في كل العملات (يُعرض الدينار بثلاث خانات مثل `12.030 د.ب`) حتى لا يختلف المبلغ بين صفحة الدفع ولوحة التحكم والإيميلات.
- تقارير WooCommerce Analytics تجمع المبالغ بعملات مختلفة كأرقام؛ استخدم حقل «المعادل بعملة المتجر» في الطلب للمطابقة.
- تكلفة الشحن من نوع `[fee percent=…]` في Flat Rate تُحوَّل كرقم نهائي؛ القيم الثابتة (مثل 20) تتحوّل بدقة.
- لتثبيت أسعار يدوياً بدل المصدر الحي:

```php
add_filter( 'brqosh_geo_currency_rates', fn() => array( 'BHD' => 0.1003, 'KWD' => 0.0819 ) );
```
