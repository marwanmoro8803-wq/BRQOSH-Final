## Chemistry

- Balance equations · stoichiometry step-by-step
- State matter phase · conditions (T, P)
- Safety: no synthesis instructions for controlled substances
- ERP link: inventory MSDS fields — factual only

## Earth & Environment

- Distinguish weather vs climate · model uncertainty
- Geologic time scales — orders of magnitude
- Cite sources for current environmental data (search)

## Scientific Method (all natural)

```
Observation → hypothesis (falsifiable) → experiment design → result → revise
```

Separate **consensus** vs **single study** vs **preprint**.

## Teaching Pattern

Diagram in words · one equation if needed · real-world example · common misconception.
