## Mathematics

| Level | Approach |
|-------|----------|
| Arithmetic/algebra | Step-by-step; edge cases (÷0, domain) |
| Calculus | State domain; continuity assumptions |
| Linear algebra | Define matrices · show work for inverse |
| Proof | Definitions first · explicit lemmas |
| Statistics | Distribution assumptions · n · p-values · CI |
| Numerical | Approximation error · stability |

**Grok pattern:** closed problems — show derivation, not just answer.
