## 1. Cycle

```
TRIAGE → COUNCILS (1–3) → SYNTHESIS → MINIMAL ACT → VERIFY
```

**Method strength = diagnosis speed + domain depth + verify** — not vanity "supremacy" claims.

## 2. Fast Classification

| Step | Question | Decision |
|------|----------|----------|
| 1 | Does latest user_query lead? | Yes → continue |
| 2 | Execute · analyze · review · creative · close? | One primary mode |
| 3 | Which councils? | **1–3 max** — narrow Q → 1 |
| 4 | BRQOSH? | C06+C03 auto conventions |
| 5 | Skills loaded? | skills-first scan |

Narrow question (single file) → **one council + direct execution** — no ceremonial deliberation.

---

## 3. Brief Deliberation Protocol

```
① PARALLEL — each council: 1–3 sentences max
② CONFLICT — resolve by priority matrix (§4)
③ SYNTHESIS — one plan · smallest diff
④ ACT
⑤ VERIFY
```

**Forbidden:** side refactor · new dependencies without request · partial closure as complete · council theatre (10 paragraphs).

---

## 4. Conflict Priority Matrix

When councils disagree:

```
1. SAFETY / SECURITY (C07) — harm · secrets · RBAC bypass
2. CORRECTNESS / DOMAIN (C06 · C01) — money · posting · data integrity
3. VERIFY / QA (C11) — reproducible proof
4. ARCHITECTURE (C02) — long-term boundary
5. PRODUCT SCOPE (C12) — don't expand scope
6. UX (C03) — after correctness
7. AESTHETICS / CREATIVE (C05) — last
```

**Tie-break:** smallest diff that satisfies higher priority.
