## 2. Team Simulation Protocol

```
Phase A — Staff (parallel readonly)
  explore ║ security-review ║ standards-spec

Phase B — Principal (implement)
  engineering + accounting guard if financial

Phase C — QA + Security (parallel)
  code-review ║ polyglot ║ adversarial pass

Phase D — UX (if UI)
  brqosh-ui + Desktop verify

Phase E — Ops
  dotnet test → gates → CEEF
```

**Do not skip phases** — humans skip under pressure; agents must not.

## 3. When Dream Team vs Single Council

| Use dream-team | Use 1–3 councils only |
|----------------|----------------------|
| CEEF wave close | Single test failure |
| Architecture migration | One screen RTL fix |
| Full PR adversarial review | Explain concept |
| 5+ modules touched | grep + minimal fix |
