# Frontend & UI Code

> **Roadmap:** [SKILL.md](SKILL.md#engineering-roadmap) | skill: supreme-programming-mastery | see per-file load order

## Principles

- Component boundaries; single responsibility
- State: local vs global — minimal global
- Accessibility: keyboard, contrast, labels
- RTL: logical properties, not mirror-only

## Web

- Semantic HTML
- CSS: design tokens / variables
- Avoid inline styles at scale

## Desktop (WPF)

- MVVM; bindings over code-behind logic
- UI thread only for UI
- Empty/loading/error states

## BRQOSH

`brqosh-ui` + `brqosh-ui-design-system` for luxury ERP RTL

## Performance

Virtualize long lists; debounce search; lazy load routes.
