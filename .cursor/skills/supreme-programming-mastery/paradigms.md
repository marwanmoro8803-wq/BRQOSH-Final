# Programming Paradigms

> **Roadmap:** [SKILL.md](SKILL.md#engineering-roadmap) | skill: supreme-programming-mastery | see per-file load order

| Paradigm | Strength | Watch |
|----------|----------|-------|
| **OOP** | Domain modeling, encapsulation | God objects, deep inheritance |
| **FP** | Immutability, pipelines | Learning curve, I/O at edges |
| **Procedural** | Scripts, glue | Global state |
| **Declarative** | SQL, UI bindings | Hidden complexity |
| **Event-driven** | Decoupling | Ordering, idempotency |
| **Reactive** | Streams | Subscription leaks |

## Choose by problem

- Business rules complex → OOP/DDD in domain layer
- Data transforms → FP pipelines
- High concurrency → actors/channels/async models per language

## Multi-paradigm (C#, TS, Python)

Use the right style per layer — don't force one everywhere.
