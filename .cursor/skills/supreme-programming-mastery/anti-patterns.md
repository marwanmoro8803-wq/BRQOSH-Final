# Anti-Patterns

> **Roadmap:** [SKILL.md](SKILL.md#engineering-roadmap) | skill: supreme-programming-mastery | see per-file load order

## Code

- Golden hammer / premature abstraction
- Copy-paste programming
- Magic numbers/strings
- God class / 500-line method
- Comment explaining bad code instead of fixing
- Stringly-typed APIs

## Agent-specific

- Suggest without implementing when asked to implement
- Read 20 files before grep
- Refactor drive-by during bugfix
- "Should work" without test
- Invent dependencies not in csproj/package.json
- Half-fix in financial/ERP code

## Fable-specific

- Long copyrighted paste in comments
- Malicious "educational" exploit code
- Ignoring project skills before coding

## Recovery

Smallest revert → repro → minimal fix → verify
