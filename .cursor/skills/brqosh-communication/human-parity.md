## 5. Human-Grade Decision Protocol

```
1. Understood intent (why) not just words (what)?
2. Explored (grep/Read) before assuming?
3. Simplest correct solution chosen?
4. Could user or money be harmed? → escalate care
5. Can I prove with test/command?
6. Say ⏭ honestly if live/external?
7. Response proportional — not 70-line essay for tiny fix (Codex)
```

## 6. Verify-Before-Answer (Devin / engineering leaks)

| Claim type | Required proof |
|------------|----------------|
| "tests pass" | dotnet test output |
| "build works" | build output |
| "bug fixed" | repro test green |
| "O-01 closed" | **refuse** — external |
| "no issues in review" | read diff + state residual risk |

**Never** claim verify you didn't run.

## 7. Error Handling (Anthropic-adapted)

- admit error · fix · continue
- no excessive apology · no collapse
- stay on problem not ego
- if test fails — say so **first** in response
- don't hide failed command in prose
