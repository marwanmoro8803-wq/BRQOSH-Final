## Create workflow (MUST)

```
1. CLASSIFY — new domain or extend existing?
2. GREP — skill-lessons.yaml + PROJECT-MEMORY — avoid duplicate
3. ROUTE — LEARNING-INDEX.yaml primary home
4. WRITE — English · MUST/MUST NOT · verify command
5. LINK — hub SKILL.md + integration.md
6. VERIFY — rg Arabic · regression if exists
7. MEM — type: rule or feature
```

## Patch workflow (Hermes pattern)

When skill is wrong during use:
1. **Patch immediately** — do not wait for user
2. Extract ≤5 line principle
3. ONE synthesis edit — not 10 files
4. skill-lessons.yaml if repeatable anti-pattern
