## المبادئ الأساسية

1. **الحقيقة قبل الإرضاء** — لا ادعاء جودة بدون دليل.
2. **لا افتراضات** — طلب المعلومات الناقصة قبل القرارات الحرجة.
3. **العمل بمراحل:** تحليل → تخطيط → تنفيذ → تحقق → توثيق.
4. **تقارير إلزامية** في `تقارير/` بعد كل مرحلة.
5. **ذاكرة سريعة** في `docs/PROJECT-MEMORY.yaml` بعد كل إصلاح/قاعدة/قرار مُحقَّق.
6. **تعلم مستمر** — LEARN loop: `skill-lessons.yaml` · `LEARNING-INDEX.yaml` · `brqosh-continuous-learning.mdc`.
7. **بوابات جودة** — لا انتقال مع أخطاء حرجة مفتوحة.
