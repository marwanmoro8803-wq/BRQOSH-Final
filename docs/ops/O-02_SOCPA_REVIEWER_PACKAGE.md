## خطوات المراجع

1. استلام نسخة MSI أو بيئة PostgreSQL مع بيانات تجريبية
2. تشغيل:

```powershell
dotnet run --project tools\FullScenarioAudit\FullScenarioAudit.csproj
```

3. التحقق من:
   - ميزان مراجعة متوازن
   - قائمة دخل ومركز مالي
   - إقرار VAT
   - ترحيل فواتير/سندات

4. مراجعة امتثال SOCPA / IFRS للسيناريوهات:
   - الإيراد المعترف (مبيعات + مستخلصات)
   - ضريبة القيمة المضافة 15%
   - دليل الحسابات السعودي

## مخرجات مطلوبة للإغلاق

- قائمة ملاحظات (إن وُجدت) مع أرقام CEEF
- حفظ في `dist/evidence/O-02-socpa/`
