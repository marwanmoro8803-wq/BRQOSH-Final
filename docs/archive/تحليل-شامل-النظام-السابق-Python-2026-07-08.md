## التحليل العام للمشروع

### البنية المعمارية

```
[Frontend SPA] ←HTTP Bearer→ [FastAPI Backend]
     ↓                              ↓
[app.js - 2092 سطر]         [Services Layer - 46 ملف]
[Vanilla JS - لا framework]  [Repository Pattern]
                              [SQLite / PostgreSQL]
```

**نقاط القوة المعمارية**:
- فصل جيد بين API Routers والـ Services
- Repository pattern مطبّق في `data_engine/`
- Middleware للأمان (CSP, HSTS, Rate Limiting)
- RBAC مطبَّق على Backend

**نقاط الضعف المعمارية**:
- **Frontend monolith**: ملف `app.js` واحد بـ 2092 سطر — صعوبة صيانة عالية
- لا يوجد state management framework — `state` object global متشابك
- لا يوجد component reuse — كل شاشة تكتب HTML من الصفر
- الـ Backend لديه تكرار: `operations.py`, `operations_core.py`, `operations_documents.py` + مشتقاتها
