# طلبُ CSID حيّ (ZATCA) — مسبارٌ لا اختبار

طلبٌ حيٌّ لشهادة الامتثال برمز OTP من [بوابة فاتورة](https://fatoora.zatca.gov.sa) — **على بوّابة المطوّرين أو
المحاكاة وحدَهما**.

> **كان هنا اختبارٌ في الحزمة** (`ZatcaLiveCsidTests`) و«بدون المتغيرات يُتخطَّى الاختبار بنجاح». **ولم يكن
> يتخطّى**: كان يرجع فيُعدّ `Passed` في كلّ تشغيلٍ ولا يُرسل شيئاً، ويُحسب في «صفرٌ متخطًّى» (`tax-zatca#15`).
> فصار أداةً تخرج بغير الصفر حين لا تُعطى الرمز.

## المتغيرات

| المتغير | مطلوب | الوصف |
| ------- | ------ | ------ |
| `BRQOSH_ZATCA_OTP` | نعم | رمز OTP من البوابة (صلاحية قصيرة) |
| `BRQOSH_ZATCA_VAT` | نعم | الرقم الضريبي 15 رقماً |
| `BRQOSH_ZATCA_ORG` | لا | اسم المنشأة في الـCSR (افتراضي: BRQOSH Probe) |
| `BRQOSH_ZATCA_API_URL` | لا | ينتهي بـ`/developer-portal` أو `/simulation` (افتراضي: بوّابة المطوّرين) — **وعنوانُ الإنتاج مرفوض** |

## التشغيل

```powershell
$env:BRQOSH_ZATCA_OTP = "<OTP>"
$env:BRQOSH_ZATCA_VAT = "<VAT15>"
dotnet run --project tools/ZatcaLiveCsidProbe
```

| الخروج | المعنى |
|---|---|
| `0` | شهادةُ امتثالٍ مكتوبة و`requestID` |
| `1` | رفضُ الهيئة أو الشبكة — والرسالةُ تقول أيّهما |
| `2` | لا رمزَ ولا رقمَ ضريبيّ — **لم يُرسَل شيء** |
| `3` | عنوانٌ ليس بوّابةَ المطوّرين ولا المحاكاة — **لم يُرسَل شيء** |

**ويكتب مفتاحَه في جذرٍ مؤقّتٍ** يطبع مسارَه — لا يمسّ `%APPDATA%\BRQOSH` ولا مفتاحَ ختم المنشأة.
**وسببُ رفض الإنتاج:** رمزُ الإنتاج يُسجّل وحدةَ إصدارٍ حقيقيّةً للمنشأة، والمسبارُ يرمي مفتاحَها بعده.

## من الواجهة

**إعدادات ZATCA → معالج CSID** (`ZatcaCsidWizardWindow`): توليدُ مفتاحٍ وCSR، ثمّ شهادةُ الامتثال، ثمّ طلبُ الإنتاج.
**ولا يبلغ شهادةَ الإنتاج بعد** — انظر `docs/ops/O-01_ZATCA_PRODUCTION_RUNBOOK.md` «ما لم يُبنَ».
